Connectors & Model Context Protocol (MCP)

Menghubungkan model kecerdasan buatan ke database internal, API pihak ketiga, dan sistem file secara terstandarisasi, aman, dan auditable.

⏱️ Waktu baca: ~11 menit
🔌 Tingkat: Lanjutan
⚙️ Contoh Config JSON
🛡️ Arsitektur Host-Server

Connector memberikan AI tiga kemampuan kritis:

👁️

Perception

Inspect database, baca file, fetch web pages, observasi sistem metrik

⚡

Actionability

Trigger workflow, kirim pesan, commit kode, invoke external API

🎯

Grounding

Akses data enterprise privat dan real-time untuk eliminasi halusinasi

Jenis-Jenis Connector

🔌

MCP Servers

Protokol standar terbuka untuk komunikasi agent-to-tool. JSON-RPC 2.0 via stdio atau SSE.

🌐

API Connectors

REST, GraphQL, gRPC — wrapper yang mengkonversi JSON function-calling ke HTTP requests.

🧩

Plugins & Extensions

Integrasi platform-specific: ChatGPT Actions, Copilot plugins, VS Code extensions.

💾

Database Connectors

SQL (PostgreSQL, MySQL), NoSQL (MongoDB), Vector DB (Pinecone, Qdrant) untuk RAG.

📁

File System

Baca/tulis file lokal, cloud storage (S3, Google Drive), parsing dokumen (PDF, DOCX).

💬

Communication

Slack, Teams, Discord, Email — kirim notifikasi, search channel history, post updates.

🔌 Model Context Protocol (MCP) — Deep Dive

"USB-C untuk Aplikasi AI" — standar universal yang menghubungkan AI model mana pun ke tool mana pun.

MCP Host Claude, VS Code, Cursor, Antigravity
↔
MCP Client Maintains connections
↔
MCP Server Exposes Tools, Resources, Prompts
📄 Resources

Client/App Controlled — Data read-only yang di-inject ke prompt (file contents, database schemas, logs).

🛠️ Tools

Model Controlled — Fungsi yang bisa dipanggil LLM. Model memutuskan kapan dan dengan argumen apa.

📝 Prompts

User Controlled — Template prompt yang bisa di-trigger user untuk memulai tugas terstruktur.

Contoh Konfigurasi MCP:

{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_TOKEN": "ghp_your_token_here"
      }
    },
    "filesystem": {
      "command": "npx",
      "args": [
        "-y", 
        "@modelcontextprotocol/server-filesystem", 
        "/path/to/allowed/directory"
      ]
    },
    "postgres": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres"],
      "env": {
        "DATABASE_URL": "postgresql://user:pass@localhost/mydb"
      }
    }
  }
}

Best Practices Connector

01

Principle of Least Privilege

Batasi database connector ke read-only. Minta konfirmasi manusia sebelum aksi destruktif.

02

Schema Minimization

50+ tool schema sekaligus menurunkan reasoning model. Gunakan dynamic tool filtering.

03

Idempotency

Tool yang mutate state harus accept idempotency key atau pre-flight check.

04

Resilience

Implement rate limiter dan exponential backoff. Return error string yang informatif.

Ringkasan — 5 Kunci Menguasai AI

01

Gunakan RACE Framework — Structure setiap prompt dengan Role, Action, Context, Expectation.

02

Engineer Context, bukan hanya Prompt — Rancang seluruh ekosistem informasi di sekitar model.

03

Kuasai teknik lanjutan — Chain of Thought, Few-Shot, dan System Prompt yang terstruktur.

04

Leverage Skills & Connectors — Kombinasikan skills modular dan hubungkan AI ke tools via MCP.

05

Tune parameter sesuai tugas — Low temperature untuk kode, tinggi untuk brainstorming.
